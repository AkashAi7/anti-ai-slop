Open the lab folder, start `npm run demo`, and choose any exercise. Node executes local checks; actual Copilot interaction happens in Chat.

## Repeatable loop

1. Prepare the learner copy with `setup`. Do not edit the starter.
2. Run `baseline`; read **why** it fails.
3. Read the task and paste the guide's prompt into a fresh Copilot chat.
4. Answer material questions, inspect the proposed change, and keep it within the allowed files.
5. Run `check`. A failure is useful feedback, not permission to weaken the checks.
6. Review the human rubric in the task. Schema checks cannot judge good product decisions.
7. Use `hint` if stuck; reveal the solution only after making an attempt.

## Completion

Explain one prevented failure for each exercise you complete. Show actual files and terminal evidence, not just an agent's confident answer. No speedup claim or universal productivity score is inferred from this workshop.

Continue with the [advanced track](advanced.md), or copy a reviewed skill into a small real task.
