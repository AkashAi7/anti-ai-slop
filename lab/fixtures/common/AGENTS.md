# Practice workspace boundaries

This is a disposable local workshop, not a production application.

- Read BRIEF.md before proposing changes. Cite existing files for code claims.
- Built-ins or public-skills cart exercise: change only src/cart.mjs and src/cart.test.mjs.
- Spec Kit exercise: change src/discount.mjs, src/discount.test.mjs, and the
  constitution and feature documents created by the installed Spec Kit workflow.
- Do not open reference fixtures unless the learner explicitly requests a solution.
- Never edit the parent lab's scripts, fixtures, tests, or acceptance checks.
- Use node:test and integer cents. Do not install dependencies or add a framework.
- Run npm test and npm run check. Report observed exit codes, not "should pass".
- Keep tool approvals enabled. Instructions are guidance, not an enforcement boundary.
- Do not commit, push, deploy, or enable automatic tool approval.
