# Dependency triage exercise

This learner workspace intentionally has no application dependencies and no
lockfile. Inspect its `package.json` and the workspace files before concluding.

Use `/dependency-triage` in read-only mode. Confirm whether there is a resolved
package or advisory to assess. Do not install packages, query a live registry,
or invent a CVE. A correct result may be that this fixture cannot demonstrate
an actual dependency vulnerability; state what files and evidence a real
application would need for triage.
