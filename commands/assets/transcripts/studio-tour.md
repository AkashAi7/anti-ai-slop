# Command Studio tour

> Recorded from the real studio page. Sample answers inside it are illustrative, not recorded Copilot output.

1. Open the Try it tab. The chat input simulates the VS Code Chat view.
2. Type / and the command palette lists built-in commands and the 12 lab prompt files.
3. Type ver to filter the palette to /verify.
4. Press Tab to pick /verify, then type the claim to check.
5. Press Enter. The studio shows the real prompt file and an illustrative sample answer ending in a verdict.
6. Mission mode shows a slop smell and asks which command fixes it.
7. Pick /clarify. The answer is scored and explained.
8. The Commands tab searches every command. Searching "context" finds the context-hygiene commands.
9. Watch mode replays the five walkthroughs, which are also exported as GIFs.

Open it yourself with `npm run studio`.
